# Contributing

Use TypeScript, arrow functions, async/await, and explicit public types. Avoid `any`. Keep routes declarative, controllers thin, and business rules and database access in services using Mongoose models. Validate new endpoints with Zod and use centralized errors and structured logging.

Never commit secrets or expose passwords/tokens. Add intentional indexes, paginate large datasets, queue expensive work, authenticate protected APIs, and authorize privileged APIs. New modules follow the feature-module structure. Run lint, typecheck, and format checks before opening a pull request.
